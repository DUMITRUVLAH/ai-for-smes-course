MCP pe înțeles

MCP e un port universal pentru AI.

Ca un port USB-C: un singur standard prin care orice agent se conectează la orice aplicație compatibilă, în loc de un cablu diferit pentru fiecare combinație.

✕

Fără un standard comun

Un conector diferit, scris manual, pentru fiecare pereche agent + aplicație: Gmail, Sheets, Slack, CRM...

N agenți × M aplicații = foarte multe conectoare custom
✓

Cu MCP

Aplicația își expune o singură dată ce poate face. Orice agent compatibil MCP se conectează prin același „port”.

ca un adaptor universal de călătorie: un port, orice aplicație compatibilă

Tip 4 · Human-in-the-loop

Review, retry și handoff.

Un workflow matur nu presupune că fiecare output e bun. Omul rămâne în buclă exact acolo unde miza e mare — nu peste tot.

Draft

agentul produce propunerea

QA

check de sursă, ton, structură

Handoff

omul aprobă cazurile sensibile

Retry

doar cu regulă și număr limitat de încercări

Run

acțiune logată și monitorizată

Când intervine omul

date lipsă sau neclare, risc/impact mare, prima interacțiune cu o instituție nouă

Ce poate face

aprobă, editează sau respinge — înainte ca acțiunea să plece efectiv

De ce contează

încredere înainte de viteză; omul rămâne responsabil pentru deciziile cu impact

Format

Fișierele .md sunt text simplu, nu magie.

Markdown: titluri cu #, liste cu -, bold cu **. Se deschide oriunde — un om și un agent îl citesc la fel de ușor.

Fără formatare ascunsăspre deosebire de Word sau PDF, nu poartă stiluri și metadate în plus
Context pentru agent, documentație pentru tineacelași fișier — reguli.md, oferta.md — servește la amândouă
Merge în Gitversionat, cu istoric de schimbări, ca orice fișier de cod
