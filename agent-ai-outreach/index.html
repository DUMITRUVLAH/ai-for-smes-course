✅ Checklist: De la ce să începi pentru a construi Agenți AI

Bazat pe structura prezentării, iată lista de subiecte de studiat pentru a-ți construi propriii agenți în mediul de dezvoltare (Cursor sau cu Claude MCP).

  • ✓
    1. Bucla Tool-Use & Decizii Învață cum gândește un agent (Obiectiv → Plan → Tool → Observă → Decide) înainte de a scrie primul rând de cod.
  • ✓
    2. API Keys & Autentificare Înțelege ce este un API Key, cum să te conectezi la alte aplicații și cel mai important: cum să ții cheile în siguranță (în `.env`).
  • ✓
    3. Model Context Protocol (MCP) Aprofundează cum MCP acționează ca un "port universal", conectând Claude de baze de date, Drive sau email fără cod complex.
  • ✓
    4. Design de Workflow-uri Practică cele 3 moduri de orchestrare: Chaining (în serie), Parallelization (în paralel) și Routing (delegare pe baza intenției).
  • ✓
    5. Sistemul de Handoff & QA uman Implementează un "Human-in-the-loop" — agentul pregătește un draft, iar tu aprobi/respingi înainte de trimiterea efectivă.
  • ✓
    6. VS Code / Cursor & CLAUDE.md Setează mediul tău de lucru și scrie instrucțiunile clare pentru agent sub formă de documentație plain text (Markdown).
