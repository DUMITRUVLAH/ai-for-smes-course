Ca un port USB-C: un singur standard prin care orice agent se conectează la orice aplicație compatibilă, în loc de un cablu diferit pentru fiecare combinație.

CLAUDE.md
# Scop

Găsește contacte publice și creează drafturi de outreach.

# Reguli

Nu inventa date. Nu trimite fără QA. Nu expune chei.

# Ordine

Harvest → verify → write → QA → send → monitor.

# Stop

Oprește pe bounce, opt-out, eroare sau lipsă de sursă.

Întrebarea de bază

Unde găsește agentul aceste instrucțiuni?

Răspunsul: un singur fișier, CLAUDE.md, pe care agentul îl citește automat la fiecare start.

Spune ordinea

Fiecare agent sau workflow știe ce are înainte și după el.

Face limitele vizibile

Regulile nu stau într-un mesaj vechi de chat.

Nu conține secrete

Cheile rămân în .env sau în Secrets.

Format

Fișierele .md sunt text simplu, nu magie.

Markdown: titluri cu #, liste cu -, bold cu **. Se deschide oriunde — un om și un agent îl citesc la fel de ușor.

Fără formatare ascunsăspre deosebire de Word sau PDF, nu poartă stiluri și metadate în plus
Context pentru agent, documentație pentru tineacelași fișier — reguli.md, oferta.md — servește la amândouă
Merge în Gitversionat, cu istoric de schimbări, ca orice fișier de cod

De ce VS Code

VS Code îți lasă proiectul la vedere.

Nu e doar un alt chat cu AI. Poți vedea fiecare fișier — contacte, reguli, loguri — nu doar promisiuni într-o conversație care dispare.

1. Vezi fișierele și foldereleContextul rămâne în proiect, nu dispare odată cu conversația.
2. Lucrezi cu agenți în tandemUnul produce, altul verifică, explică sau auditează.
3. Păstrezi urmeleRegistru contacte, template, reguli și loguri în același loc.
4. Alegi orice LLMChatGPT, Claude, Gemini și altele — nu ești legat de un singur model.
